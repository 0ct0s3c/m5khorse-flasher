TECHNICAL SUPPORT / NO EXORCIST ON STAFF

Shit's not working.

A diagnosis first. A small breakdown later.
Let's start with the cable.

My PaperMono doesn't appear.

Try a USB data cable; some cables only supply power. A charging cable with career ambitions is still a charging cable. Close serial monitors, M5Burner and other flasher tabs. Hold the power button for about 2 seconds until the red LED blinks, release it, then choose Connect PaperMono again. M5Stack's board guide ↗

Will this erase my books or settings?

This installer writes four firmware segments and does not erase the whole chip. It preserves KEY-HORSE's NVS settings, including your PIN, and never accesses the microSD card. A first install replaces the previous firmware; settings from other firmware may not be compatible. Keep copies of files you value. The horse is many things. A backup strategy is not one of them.

The installation was interrupted.

Some firmware bytes may already have been written. Check the device and installation log before starting another attempt. Restore the USB connection and enter download mode if recovery is needed. The flasher never automatically repeats an installation.

It says verified, but the screen hasn't changed.

The e-paper panel retains its image without power. After verification, let the device restart and give the first refresh a moment. The screen can display yesterday's bullshit without a single electron of enthusiasm. If needed, briefly press the power button to restart. Verification checks flash bytes; check the screen, touch and NFC on the device separately.

Can I install without this browser?

Use desktop Chrome or Edge on a computer with USB serial support. This page supplies the firmware; no Python, compiler or local server is needed. Open Release files below for the four flash segments and their manifest if you use another installer. Match the offsets and verify every write. Guesswork is for my Tarot readings.
