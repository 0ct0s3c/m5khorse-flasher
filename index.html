03 / TECHNICAL SUPPORT, SOMEHOW

Shit's not working.

Mercury is not in retrograde. Your cable might be shit.
Let's establish which problem we actually have.

My PaperMono doesn't appear.

Use a USB data cable; a charging-only cable cannot carry firmware. Close serial monitors, M5Burner and other flasher tabs. Hold the power button for about 2 seconds until the red LED blinks, release it, then choose Connect PaperMono again. M5Stack's board guide ↗

What happens to my books, horse and PIN?

This installer writes four firmware segments and does not erase the whole chip. It preserves KEY-HORSE settings, horse progress and your existing device PIN, and never accesses the microSD card. An update does not remove a forgotten PIN. A first install replaces the previous firmware; settings from other firmware may not be compatible. Keep copies of files you value. The horse is many things. A backup strategy is not one of them.

The installation was interrupted.

Some firmware bytes may already have been written. Choose Save log before closing or reloading this page. Check the device and the four segment results: Verified means the device digest matched; Not verified means the result is uncertain; Not written means that segment was not reached.

If recovery is needed, restore the USB connection, enter download mode, then reload this page to begin a new attempt. The flasher never automatically repeats an installation.

It says verified, but the screen hasn't changed.

The e-paper panel retains its image without power, so an unchanged picture does not tell you whether the new firmware is running. After verification, wait for the first refresh. If needed, briefly press the power button to restart, then unlock with your existing PIN if one is set. Check the screen, touch and NFC on the device; flash verification checks the written bytes. E-paper can hold a grudge with the battery out.

Can I install without this browser?

Use desktop Chrome or Edge on a computer with USB serial support. This page supplies the firmware; no Python, compiler or local server is needed. Open Release files below for the four flash segments and their manifest if you use another installer. Match the offsets and verify every write. Guesswork is for my Tarot readings.
