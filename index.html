Use a USB data cable; a charging-only cable cannot carry firmware. Close serial monitors, M5Burner and other flasher tabs. Hold the power button for about 2 seconds until the red LED blinks, release it, then choose Connect PaperMono again. A charging icon only proves power. Even a fucking toaster can manage that. What happens to my books, horse and PIN?

This installer writes four firmware segments and does not erase the whole chip. It preserves KEY-HORSE settings, horse progress and your existing device PIN, and never accesses the microSD card. An update does not remove a forgotten PIN. A first install replaces the previous firmware; settings from other firmware may not be compatible. Keep copies of files you value. The horse has four hands, and every single one will point at somebody else if you ask where your backup is.

The installation was interrupted.

Some firmware bytes may already have been written. Choose Save log before closing or reloading this page. Check the device and the four segment results: Verified means the device digest matched; Not verified means the result is uncertain; Not written means that segment was not reached.

If recovery is needed, restore the USB connection, enter download mode, then reload this page to begin a new attempt. The flasher never automatically repeats an installation. “Again, but more frightened” is not a recovery procedure.

It says verified, but the screen hasn't changed.

The e-paper panel retains its image without power, so an unchanged picture does not tell you whether the new firmware is running. After verification, wait for the first refresh. If needed, briefly press the power button to restart, then unlock with your existing PIN if one is set. Check the screen, touch and NFC on the device; flash verification checks the written bytes. That's e-paper: a screen that can tell you to fuck off after you've unplugged it.

The firmware package won't load.

Check your internet connection, then choose Check the package again in the installer. For a downloaded flasher, extract the whole ZIP, run its launcher and keep the launcher window open. Opening index.html directly will not work. That's a front door lying in a field. The rest of the house matters.

Package checks only download and verify files; they do not open USB or write to your device. If a check keeps failing, save the installation log before reloading. The horse's entire diagnosis is “bollocks.” The log has more detail. Return to the installer ↑

Can I install without this browser?

USB installation needs desktop Chrome or Edge with USB serial support, over HTTPS or localhost. In other browsers you can still draw cards, read the setup instructions and download the firmware. Predicting the future is open to everyone. Touching a USB port apparently requires a fucking chaperone.

Using another installer? Download all four segments and their manifest, use the listed flash offsets and verify every write. Flash offsets are addresses, not lottery numbers.
